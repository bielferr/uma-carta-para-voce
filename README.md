## Uma carta para voce

        Uma experiência interativa criada como presente de aniversário.

    Inspirado na atmosfera mágica de contos de fadas, o projeto convida o usuário a abrir um envelope que revela uma carta especial, acompanhada por música, animações suaves e lanternas flutuantes.
 
## Link para viualização 
    https://uma-carta-para-voce-zeta.vercel.app/

## 🛠️ Stacks

- Next.js 15
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Howler.js
- React Icons
